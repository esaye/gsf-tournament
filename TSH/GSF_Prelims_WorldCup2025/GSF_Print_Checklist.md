### 🚨 **Emergency Procedures**

#### **If Digital System Fails:**
1. Use physical scoresheets exclusively
2. TD manually enters scores via Oslo
3. Update live system once connection restored
4. Continue tournament with paper backup

#### **If Player Can't Access System:**
1. Use physical scoresheet
2. Tournament assistant enters score digitally
3. Both players sign physical backup
4. File physical sheet for records
