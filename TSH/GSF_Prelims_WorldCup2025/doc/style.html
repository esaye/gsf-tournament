Style sheet for proofreading tsh documentation

1–10 — that’s right.
Use en and em dashes and curly apostrophes, not vertical quotes, except in <title>.
“double quotes around quoted text”
Except I suppose for nested dialogue, of which we have none.
“command names and other input text are in monospace”
Except in table listing all commands, where quotation marks are omitted. Command names are given in MixedCase with capital letters showing permissible abbreviations when shown in their longest form, and in lower case when showing the abbreviated form.
“things which are quoted and in Roman type”
Names of keyboard keys, filenames or parts thereof.
Paragraph indentation
Use class=p1 for small first-line indentation, always.
tsh
Is tagged using <cite>, except in <title>.
emphasized text
Is tagged using <em>, not <i>.
his/her, s/he
Are used rather than their, them.
